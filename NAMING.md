**Usage rules**

1. Put the mark on the **first prominent mention** in each Markdown file (title, subtitle, or opening definition). Later mentions in the same file may omit the mark for readability.
2. Use **™** / **℠** only — do **not** use **®** unless a mark is registered and the author authorizes it.
3. Marks identify the author's original pattern names; they do **not** change the dual license on code/prose. See [LICENSING.md](LICENSING.md).

## What these names mean legally

- The names **identify the author's original methodologies**. When you discuss or reuse the ideas from this book, **attribute and cite** Vaquar Khan.
- **Copyright** covers the written expression (book text, diagrams, formal specs). See [LICENSING.md](LICENSING.md) and [COPYRIGHT.md](COPYRIGHT.md).
- **™** and **℠** are used as common-law identifiers for the pattern names above. **No registered trademark (®) is claimed** in this repository unless explicitly stated.
