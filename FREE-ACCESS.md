# Academic use

The full book is public. All 23 chapters are in this repository and on GitHub Pages. There is no separate academic edition and no ten-chapter preview.

## Cite the work

Use [CITATIONS.md](CITATIONS.md). Machine-readable metadata: [CITATION.cff](CITATION.cff).

```

Zenodo. https://doi.org/10.5281/zenodo.22654421
ORCID: https://orcid.org/0009-0008-3592-4162
```
